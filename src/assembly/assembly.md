# A³ Assembly

The A³ devices are built by hand from parts anyone can get. The **boards** are designed in KiCad
and ordered from a PCB manufacturer from the production files in each device's repository
(`hardware/pcb/<revision>/`), then fitted by hand. The **housings** are designed in FreeCAD and
printed on an ordinary FDM 3D printer (`hardware/housing/`). The shared parts library for the
boards is [a3-kicad-lib](https://github.com/a3-audio/a3-kicad-lib).

What belongs to which version — every repository, board revision and housing — is on the
{doc}`A³ System <../user/a3system>` page.
